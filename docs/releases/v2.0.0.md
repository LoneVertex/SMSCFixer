## What is new

SMSC Guard introduces a modern launcher and adaptive icon built around a protected telecom routing symbol, a consistent public product name, and a package namespace owned under the LoneVertex GitHub identity. The underlying safety program remains in place: exact supported send-signature allowlisting, preserve-on-unknown/conflicting routing behavior, fail-safe target scope, bounded routing metadata cache, redacted diagnostics, LSPosed-managed preference support where available, and controlled release-candidate evidence.

CI now compiles the Android instrumentation-test APK in addition to lint, JVM tests, and debug/release application artifacts. Release-candidate manifests bind the application ID, release tag, version name, version code, commit, and artifact digest.

## Important migration notice

This version is a **new Android application installation**. It does not update the former `com.smscfixer` package, and it does not automatically retain prior LSPosed scope or settings. Follow `docs/production/smsc-guard-v2-migration.md` before enabling the module on any device.

## Verification completed locally

The v2.0.0 source build passed lint, JVM tests, debug APK assembly, unsigned release APK assembly, and instrumentation-test APK compilation. APK inspection confirmed the `io.github.lonevertex.smscguard` application ID, `2.0.0` / `2000000` version metadata, SMSC Guard labels, adaptive launcher icon references, renamed Settings activity, and renamed LSPosed entry asset. The current review source is published on [`manus/smsc-guard-v2-release-candidate`](https://github.com/LoneVertex/SMSCFixer/tree/manus/smsc-guard-v2-release-candidate) in [pull request #4](https://github.com/LoneVertex/SMSCFixer/pull/4).

## Release gates still required

The candidate remains unsigned until an external controlled signing step verifies the candidate manifest and records the signing certificate digest. Before any broad rollout, complete rooted-device LSPosed testing, approved controlled carrier-delivery cases, and a signed-artifact rollback rehearsal. No release publication, device installation, or SMS delivery is performed by this document.
