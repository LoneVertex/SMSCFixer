## What is New in v2.0.0

- **Libxposed API 102 Migration:** Completely migrated from legacy `de.robv.android.xposed:api:82` to modern `io.github.libxposed:api:102.0.0` and `io.github.libxposed:service:102.0.0`.
- **Modern Packaging & Scoped Injection:** Configured `META-INF/xposed/` metadata packaging (`module.prop`, `java_init.list`, `scope.list`), strictly scoping injection to telephony and messaging stacks (`com.android.phone`, `com.android.mms.service`, `com.google.android.apps.messaging`).
- **Secure Service IPC:** Completely abolished `xposedsharedprefs` and obsolete world-readable filesystem modes (`Context.MODE_WORLD_READABLE`). Settings are now synchronized across processes via `io.github.libxposed.service.XposedProvider` and `RemotePreferences`.
- **Zero-Dependency Reflection Core (`ReflectUtils`):** Eliminated all reliance on `XposedHelpers`. Built on thread-safe, cached Java reflection with primitive widening, wrapper assignability, and null-argument resolution.
- **Material 3 Dynamic Settings Dashboard:** Replaced legacy XML activities with a fully reactive Jetpack Compose Material 3 dashboard displaying live LSPosed framework connection telemetry badges, per-slot SMSC configurations, and target scope chips.
- **Fail-Safe Preserving Logic:** Enhanced decision policies to guarantee that ambiguous signals or unrecognized carriers strictly preserve original SMSC values rather than failing or misrouting.
- **Cryptographic Release Signing:** Verified and signed with a dedicated 4096-bit RSA release key covering APK Signature Schemes v1, v2, and v3.

## Important Migration Notice

Version 2.0.0 is a **new Android application installation**. It replaces the former `com.smscfixer` package identity. Because the application ID changed to `io.github.lonevertex.smscguard`, prior LSPosed scope and stored settings do not migrate automatically. Review `docs/production/smsc-guard-v2-migration.md` for controlled device migration instructions.
