## What is New in v2.1.0

- **"The Routed Shield" Launcher Identity:** Production-ready Adaptive Launcher Icon and Material You Themed Icon (`ic_launcher_monochrome`) conforming to Android API 36 adaptive icon guidelines with 108dp viewport, safe-zone circular masking, and dynamic system color integration.
- **Canonical LSPosed Scope Declaration:** Configured `<meta-data android:name="xposedscope" android:resource="@array/xposed_scope" />` in `AndroidManifest.xml` with companion `@array/xposed_scope` (`android`, `com.google.android.apps.messaging`, `com.android.mms`) to enable automated module target recommendations in LSPosed Manager.
- **Open Source Community Architecture:** Published complete open-source governance documentation including MIT License, Contributor Covenant v2.1 Code of Conduct, Security vulnerability disclosure policy (`minaalaa141@gmail.com`), GitHub Issue Forms, CI-enforced Pull Request Template, and comprehensive `CONTRIBUTING.md` developer guide.
- **Config Schema Decoupling:** Centralized default package scope resolution into `SmscConfigSchema.defaultTargetPackages()`, eliminating circular compile dependencies between `SmscRuntimeConfig` and `SmscConfigSchema`.
- **Encapsulated Preferences Persistence:** Encapsulated preference persistence within `PreferencesManager.saveSettings()`, cleanly separating the Compose UI ViewModel from low-level `SharedPreferences.Editor` manipulations.
- **UI Localization Hardening:** Extracted all user-facing status messages and telemetry badges into `res/values/strings.xml` with dynamic format argument support.
- **Anti-Koshary Architectural Hardening:** Flattened nested try-catch reflection routines in `RoutingSignalResolver.java` into discrete modular helpers (`getTelephonyManager`, `resolveScopedTelephony`, `readSimOperatorName`, `readSimOperator`).
- **Dead Code Pruning:** Purged deprecated `isLsposedManaged` and `makePrefsReadableForXposed()` stubs and pruned obsolete 5-parameter constructors in `ConfigurationRepository.java`.
- **Deterministic Quality Gate:** 81/81 hermetic unit tests passing across all layers, 0 Android Lint errors, and verified clean release builds.
